# Hybrid Coupler with Stubs

## Overview

Analysis of a practical hybrid coupler with the introduction of stubs.

## Objective

Stubs were introduced into the practical hybrid coupler to investigate their effect on the RF characteristics of the structure.

## Design

The modified hybrid coupler was simulated using Keysight ADS.

## Analysis

The effect of the stubs was evaluated through:

- S-parameters
- Return loss
- Insertion loss
- Phase response
- Impedance matching
